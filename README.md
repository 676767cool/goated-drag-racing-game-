# GOATED Drag Racing

A browser-based drag-racing and engine-building game built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Features

- Engine and forced-induction parts
- Drag-body selection
- Dyno output and estimated quarter-mile time
- Reaction-time-style drag race
- Separate horsepower and quarter-mile leaderboards
- Local browser saves
